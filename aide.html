Comment pouvons-nous vous aider ?

Sélectionnez votre profil pour accéder aux guides personnalisés.

🧭

Naviguer sur le site

1

L'Accueil

C'est la page par défaut. Vous y voyez les dernières annonces publiées à Brazzaville.

2

La Carte Interactive

Cliquez sur l'onglet Carte dans la barre de navigation en bas. Visualisez géographiquement tous les biens disponibles. Utilisez les boutons + et - pour zoomer/dézoomer.

3

Recherche Avancée

Dans le menu supérieur (sous le logo), cliquez sur Rechercher. Filtrez par Arrondissement, Quartier, Type de bien ou Prix (croissant/décroissant).

❤️

Interagir avec une annonce

A

Voir les détails

Cliquez directement sur une carte d'annonce sur l'accueil ou la carte. Vous verrez les photos, la description complète, le prix exact et les coordonnées du vendeur.

B

Contacter le prestataire

Sur la fiche détail, utilisez le bouton vert WhatsApp pour discuter directement avec l'agent immobilier ou le propriétaire.

C

Mettre en Favori

Cliquez sur l'icône Cœur 🤍 (blanc) sur la vignette de l'annonce. Si elle devient Rouge ❤️, c'est qu'elle est sauvegardée. Retrouvez-la via l'onglet Favoris en bas.

D

Partager une annonce

Cliquez sur l'icône Boîte avec Flèche 📤. Choisissez l'application (WhatsApp, SMS, Copier lien) pour envoyer l'annonce à vos proches.

E

Signaler une annonce suspecte

Sur la fiche détail, cherchez le bouton Signaler (souvent à droite). Sélectionnez le motif (Arnaque, Fausses infos...) et validez. L'admin recevra votre alerte immédiatement.

⚙️

Mon Compte & Historique

1

Voir mon Profil

Cliquez sur votre Nom en haut à droite. Vous accédez à votre espace personnel pour modifier vos infos (Nom, Téléphone, Mot de passe).

2

Historique de visite

Allez dans Plus > Mes Activités. Vous retrouverez la liste des annonces que vous avez consultées récemment.

3

Gestion des données

Dans Plus > Données, vous pouvez vider le cache local ou voir vos statistiques d'utilisation.

4

Se déconnecter

Descendez tout en bas de la page Profil et cliquez sur le bouton rouge Se déconnecter.

🏢

Guide Exclusif Prestataire

En tant que prestataire, vous avez accès à toutes les fonctionnalités clients PLUS la gestion professionnelle de vos annonces.

📝

Publier une nouvelle annonce

1

Accéder au formulaire

Vous avez 3 moyens rapides :

  • Bouton + Publier en haut à droite du header.
  • Onglet Publier dans le menu horizontal sous le logo.
  • Bouton Publier une annonce si votre section "Mes annonces" est vide.
2

Remplir les informations clés

Saisissez impérativement :

  • Titre : Clair et attractif (ex: "Villa moderne avec piscine").
  • Prix : En FCFA.
  • Type : Maison, Appartement, Chambre, Terrain.
  • Localisation : Arrondissement, Quartier et Adresse exacte.
  • Nombre de pièces : Indiquez combien il y a de chambres/pièces.
  • Description : Détaillez les commodités (eau, électricité, parking, etc.).
  • Contact : Votre numéro de téléphone pour être joignable.
3

Ajouter des photos

Uploitez jusqu'à 3 photos de qualité. Privilégiez la luminosité et la netteté. Une belle photo augmente considérablement les contacts.

4

Valider

Cliquez sur Publier l'annonce. Votre offre apparaîtra immédiatement en tête de liste sur l'accueil (car triée par date récente).

📋

Gérer mes annonces publiées

1

Accéder à "Mes annonces"

Cliquez sur l'onglet Mes annonces dans la barre de navigation basse.

2

Modifier une annonce

Si le prix change ou si vous voulez corriger une faute, cliquez sur le crayon ✏️ ou le bouton Modifier associé à l'annonce. Mettez à jour les champs et sauvegardez.

3

Supprimer une annonce

Si le bien est vendu ou loué, cliquez sur la corbeille 🗑️ ou Supprimer. L'annonce disparaîtra définitivement du site public.

4

Voir les détails publics

Cliquez sur l'œil 👁️ ou le titre de l'annonce pour prévisualiser comment elle apparaît pour vos clients.
