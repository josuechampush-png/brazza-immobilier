# Brazza-Immobilier

**Brazza-Immobilier** est une plateforme web d'annonces immobilières dédiée à Brazzaville, au Congo. Elle permet de trouver des maisons, des appartements et des chambres à louer, et de contacter directement les propriétaires.

🌐 **Site en ligne :** https://brazza-immobilier.onrender.com

## Créateur

**Josué Soumbou** — créateur et développeur web de Brazza-Immobilier, basé à Brazzaville, Congo.

## Fonctionnalités

- Recherche avancée par arrondissement, quartier, type de logement, nombre de pièces et prix
- Couverture des 10 arrondissements de Brazzaville
- Publication d'annonces avec photos
- Contact direct avec les propriétaires via WhatsApp
- Favoris et historique des annonces consultées
- Carte des annonces
- Mode sombre
- Application installable sur mobile (PWA)

## Technologies

- HTML, CSS, JavaScript
- Supabase (base de données et authentification)
- Hébergement sur Render
